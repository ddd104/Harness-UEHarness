## 强制边界

- 仅实现项目级 Editor-only C++/Slate 插件 AgentWorkbench，不修改引擎源码，不引入网页 UI 或外部服务来替代原生编辑器窗口。
- 固定三栏布局：历史 / 对话 / 执行详情。候选资产面板位于对话记录下方、输入框上方。
- 一个新窗口创建一个新 Session。每个 Session 的消息、候选资产、模型选项、Runner 和取消状态独立。
- 新建空窗口和未发送草稿不形成历史；首次有效发送开始 Run 后才加入历史并持久化。关闭未发送窗口时丢弃临时 Session。
- 点击历史在当前窗口切换 Session；目标已在另一窗口打开时交换两个窗口显示的 Session，保持一个 Session 只有一个可写窗口。历史右键菜单提供重命名、删除和新建分叉；选中历史后 F2 重命名、Delete 删除。分叉产生独立 Session。
- Content Browser 选择变化不自动添加、不自动发送。只有目标窗口中的显式操作才能改变该 Session 的候选列表。
- 候选列表只存软引用路径与轻量元数据；移除或清空候选不能删除或修改真实资产。
- 发送时冻结模型选项、对话输入和当前候选资产。工具只使用该 Run 的快照，不再查询全局编辑器选择。
- 取消、超时、回调至少校验 SessionId/RunId/RequestId 或 ToolCallId。旧回调不得污染新任务。
- UObject/Slate 状态在 Game Thread 访问和变更；异步边界使用正确的对象生命周期管理和弱引用。
- 项目设置只存凭据环境变量名称；不要读取并打印密钥、枚举环境变量、记录 Authorization、提交 .env 或把凭据持久化。
- 首版仅提供经过注册与参数校验的只读工具，不执行任意 shell，不创建、删除、重命名、编译或保存真实蓝图。
- 不依赖 FString 字符串拼接来生成 JSON；使用 JSON 库。
- 不修改与当前阶段无关的代码，不撤销用户改动，不自动提交、推送或执行破坏性 Git 操作。

## 验证与交付

每阶段先实现最小可验证改动，再实际运行可用的构建和测试，最后检查 diff。
只有拿到真实结果，才可报告编译通过或测试通过；没有引擎、无法运行编辑器、缺少 Key 等分别标记为阻塞或未验证。
更新 PROGRESS.md，分别记录“代码状态 / 编译状态 / 自动化测试 / 编辑器内验收”。
最终汇报改动文件、执行命令、结果、未验证项和下一阶段，不把 TODO、空回调或模拟数据当成真实功能完成。
