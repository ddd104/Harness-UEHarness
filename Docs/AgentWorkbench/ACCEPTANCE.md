# 验收清单

所有条目初始均为未验证。代码审查、编译、自动化和编辑器手工测试是不同证据，不可互相冒充。
自动化建议使用 UE Automation Framework，并对选择来源、模型 Provider、时钟、存储和调度注入可控替身；实际集成行为仍需编辑器内确认。

| C07 | MaxConcurrentRuns=1，A 运行、B 排队，取消 B | A 不变；B 不开始执行 | 自动化 |

## E. 模型、工具与凭据

| 编号 | 操作 | 预期 | 建议验证 |
|---|---|---|---|

## 验收记录格式

每条记录包括：编号、实现位置、证据类型、实际命令/操作、结果、日志或截图位置、日期、限制。
状态只允许：已验证通过 / 失败 / 代码已实现但未验证 / 未实现。
可以在没有图形环境时完成纯逻辑测试，但不能据此将 UI 操作标记为已验证。
