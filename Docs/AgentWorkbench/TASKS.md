# 分阶段实施任务

通用要求：每个阶段只完成本阶段和必要修复，保持其他模块不变。执行真实构建/测试并更新 PROGRESS.md。未执行的检查标为未验证。
现有界面、候选列表、会话隔离、真实 Provider 和工具调用循环已完成；UE5.8 MCP 工具可通过目录按需调用并逐次审批。本机 26 个 Toolset 插件已加入 Editor 配置，在独立 DebugGame 编辑器中发现 876 个工具；当前 Development 编辑器还需重新链接并重启。无凭据时显示配置错误，不产生伪造回复。全局并发排队与蓝图图结构读取仍待实现。

## P0：工程勘察与计划

检查现有规则和 git status，确认 .uproject、EngineAssociation、能够解析到的引擎版本、引擎目录、Editor Target、平台、现有插件、可用构建/测试流程。
检查本地 ToolMenus、Slate 窗口、ContentBrowser、AssetData、DeveloperSettings、HTTP 等关键接口。
识别是否已有模型客户端和工具系统，优先复用合适的基础设施，不直接复制整个旧模块。
将发现、实际构建命令、计划文件列表和阻塞记录到 PROGRESS.md。

退出条件：明确实际目标和未知项；不得把网上文档版本当成用户引擎版本。首次任务完成 P0 后继续 P1，不只输出计划。

## P1：插件骨架、多窗口、固定布局、设置

创建 Editor-only 插件、模块和工具栏入口。每次新建生成独立 SessionId/Session/Runner 占位状态和非模态 SWindow。
实现完整三栏 Widget 骨架；候选区必须已位于对话与输入之间，支持空态，不先删掉等后面再改布局。
实现模型栏、草稿输入、发送/停止状态、结构化执行区和会话内消息展示；连接名称从项目设置读取。
实现 UDeveloperSettings 的环境变量名称、默认模型、三个超时和限制参数。
会话内修改模型和草稿彼此独立；新窗口和未发送草稿不进入历史，首次有效发送开始 Run 后才展示并保存；历史区左键在当前窗口切换，右键菜单可重命名、删除或新建分叉；选中行支持 F2 重命名和 Delete 删除。
关闭任一窗口不关闭其他窗口，正常退出解除菜单和窗口绑定。

退出条件：Editor Target 可构建；可打开三个窗口；结构与 SPEC 一致；输入和模型不串窗口。
只有静态审查环境时，仍交付完整源文件并明确编辑器内状态未验证。
不要为 P1 接真实网络或实现任意写工具。

## P2：真实 Content Browser 选中资产 → Session 候选 → 请求快照

实现 FAgentAssetContextService、候选 DTO 和候选 Widget。
读取主 Content Browser 的选中资产，支持多选、排除重定向器、路径规范化、去重、追加；默认 /Game/ Content 资产，不限蓝图。
候选行只显示完整 Object Path 和右侧 X；完成移除、清空、空态、超限和错误提示。
实现按 Session 保存候选；发送时复制为 RunInputSnapshot；请求详情显示实际发送的模型输入及候选对象路径。
完成 list_context_assets/get_asset_metadata 的可测试逻辑；不需要真实 Key。
禁止 UI Tick/选择事件自动批量加载蓝图，禁止后台线程读取 UObject。

退出条件：A/B 候选独立；A 发送后改变选择或候选不改变当前快照；重复添加不增加条目；移除不改变真实资产。
补充自动化测试：蓝图及非蓝图资产添加、重定向器过滤、去重、跨 Session 隔离、快照值语义、无候选、超限和无效路径。

## P3：执行器与并发隔离

实现 Runner 状态机和模型→工具→模型循环；用可控测试传输模拟延迟、乱序回调、失败、超时和取消后回调，不在用户对话中生成测试回复。
每次发送新 RunId，每次请求/重试新 RequestId；工具调用 ID 独立，防重复推进。
实现请求超时、工具超时、Run 总超时、步骤上限、全局并发限额及公平的可预测排队。
支持取消排队/正在请求/正在工具阶段任务，不影响其他 Session。
模型参数、候选资产和输入全部从发送时快照读取。
实现关闭请求确认，弱引用事件绑定，以及模块退出期间停止接受新工作。

退出条件：自动化覆盖双 Session 并发、取消隔离、迟到响应、工具迟到/重复结果、参数快照、候选快照、排队取消和退出无回调泄漏。
测试优先使用可控调度器/时钟，不用长时间 Sleep 让测试依赖随机时序。

## P4：历史持久化与恢复

实现版本化 session.json、可重建 index、按需 events.jsonl；同一 Session 及共享索引写入有序。
保存结构化消息、模型参数、候选条目、草稿和 Run 摘要，不保存凭据或运行时对象。
恢复、历史搜索、当前窗口切换历史和完整检查点分叉；会话候选使用值副本。
执行中异常退出后标记 Interrupted，不重放工具。
处理保存失败、索引丢失、单文件损坏、资产失效/移动和注册表未就绪。

退出条件：重启后恢复；候选路径/模型与原会话一致；分叉后两边修改互不影响；坏索引可重建；密钥扫描未发现泄漏。
已有 Run 快照和历史输入不因当前资产列表变化而改写。

## P5：真实模型适配器和只读蓝图读取

优先复用现有明确的模型协议。没有现成协议时实现一个明确的 Chat Completions 兼容适配器，能力和 endpoint 语义写进文档。
模型名字由配置提供；先实现非流式即可，流式能力未实现时禁用对应选项并解释，不能假装支持。
运行时通过环境变量获取凭据。实现 HTTP 状态/JSON/服务端错误/工具参数/响应关联校验、脱敏和取消。
只对策略允许的网络失败重试，限制重试次数；不自动重放具有未知副作用的工具或任务。
实现 read_blueprint_asset，真实返回目标资产结构的受限快照，不自动编译、保存或修改。
只读资产元数据和蓝图变量工具校验 `/Game` 路径、资产存在性及类型；打开资产编辑器只接受本 Run 候选快照中的非关卡资产，越界访问返回结构化错误。
模型请求、工具参数、读取路径和结果在执行区可见。
对协议解析和错误路径建立离线固定样本测试；真实 Key 测试是单独的集成项。

退出条件：至少一个已配置的真实服务能够完成“用户请求→模型工具调用→读取候选蓝图→模型回复”。
缺 Key/服务环境时，真实闭环记为未验证，不能声称首版最终验收通过。

执行 ACCEPTANCE.md，优先回归多窗口、候选快照、取消、退出和历史。
检查模块依赖、反射类型生成、头文件、异步回调、强引用环、路径权限和凭据泄漏。
在真实 Editor Target 做可用的完整构建，不只依赖 Live Coding 的一次成功。

交付改动清单、构建日志位置、测试摘要与未验证清单；不自动提交/推送。
